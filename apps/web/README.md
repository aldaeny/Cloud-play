# واجهة Cloud Play

واجهة الويب في هذا المجلد هي معاينة Next.js تدعم العربية والإنجليزية والوضعين الفاتح والداكن. تحتوي عناوين وصوراً تجريبية، وإعدادات محلية للمظهر واللغة والحركة. تسجيل الدخول للمستخدم غير مرتبط. توجد تجربة محدودة لقنوات Firebase وتشغيل HLS الخارجي المباشر كما هو موضح أدناه.

## تشغيل الواجهة محلياً
من جذر المشروع:
```sh
npm ci
npm run dev -w apps/web
```
افتح `http://localhost:3001`. للتأكد من البناء:
```sh
npm run lint -w apps/web
npm run build -w apps/web
```

راجع `../../FREE_LOCAL_SETUP.md` لتجربة الخدمات الأخرى و`../../FINAL_REPORT.md` لحدود التنفيذ والاختبار. Docker غير مختبر هنا، والمشروع غير جاهز للإطلاق العام.

## كتالوج Xtream اختياري
راجع `../../XTREAM_LOCAL_SETUP.md`. أضيفت قراءة تصنيفات وقنوات من خلال الخادم؛ نموذج الإعداد المحلي يسمح بـHTTP بطلب المستخدم، وبيانات الاعتماد فارغة. اختُبرت بخادم وهمي فقط. لا يوجد تشغيل فيديو عبر موصل Xtream، وHTTP يعرّض بيانات الدخول للاعتراض.

## تجربة قائمة Firebase
من قسم TV اضغط «عرض القنوات» ثم اختر قناة مؤهلة واضغط تشغيل في الفيديو. القائمة عامة، لكن يجب التأكد من حقوق الاستخدام قبل النشر. في الاختبار تأهل رابطان من سبعة وشغلا في Chromium؛ البقية غير مفعلة، والبث يعتمد على توفر المصدر والمتصفح. الروابط المسموح بها تصل للمتصفح وقد تكشف بيانات داخل المسار؛ تجنب استخدامها إن احتوت معلومات حساسة. اختبار التنقية المحلي: `node scripts/firebase-catalog-smoke.js`. لا يوجد proxy أو تجاوز حماية.

## أفلام مجانية مرخصة
قسم «أفلام قصيرة مفتوحة» يعرض Big Buck Bunny وSintel مع الإسناد وتراخيص CC BY وروابط صفحات المصدر؛ يتم تشغيل MP4 مباشرة من Internet Archive. يجب الالتزام بنص الترخيص والإسناد عند النشر. يعتمد التشغيل على المصدر الخارجي، وهذه عناوين قصيرة مجانية وليست كتالوجاً تجارياً. اختُبر بدء تشغيل الفيلمين في Chromium بنافذة هاتف.

## قنوات العراق
قسم TV يتضمن زر «عرض قنوات العراق» لقائمة iptv-org العامة. يعرض كل الأسماء ويحاول تشغيل روابط HTTPS HLS المؤهلة مباشرة من مزوديها باستخدام المتصفح؛ الروابط التي تستخدم HTTP أو معاملات أو منافذ غير 443 أو خيارات تشغيل خاصة معطلة. اجتياز الفلتر لا يعني نجاح التشغيل، وتعتمد النتيجة على المصدر وCORS وترميز المتصفح. يجب التأكد من حقوق العرض. `node scripts/iraq-playlist-smoke.js` يختبر التحليل والتنقية ببيانات وهمية.

## قائمة المنطقة العربية
في TV اضغط «عرض قنوات المنطقة العربية» وابحث بالاسم. القائمة من iptv-org وهي حسب المنطقة وقد تضم قنوات بلغات أخرى. الروابط المؤهلة للتجربة هي HTTPS HLS غير محتوية على معاملات أو بيانات اعتماد أو منافذ مخصصة ولا تحتاج إعدادات VLC خاصة؛ قابلية المحاولة لا تعني توفر البث أو توفر إذن عرضه. اتصالات التشغيل مباشرة بمزود خارجي. تُتاح قائمة العراق بشكل منفصل وبها البحث نفسه.

## قنوات العالم
اضغط «عرض قنوات العالم» في TV. القائمة العالمية من iptv-org تُعرض في صفحات من 60 نتيجة؛ ابحث باسم القناة ثم اضغط «بحث». ليست كل الروابط مؤهلة أو متاحة للتشغيل، ومزودو القنوات خارجيون ويجب التحقق من حقوق العرض. المصدر ثابت لا يقبل روابط عشوائية من المستخدم؛ البحث محلي على كاش الخادم. اختبار التنقية `node scripts/iraq-playlist-smoke.js`.

## بدء التشغيل
يحاول المشغّل بدء الفيلم أو القناة تلقائياً؛ إذا منع المتصفح ذلك اضغط «تشغيل الآن». في حالة فشل المصدر يظهر زر «إعادة المحاولة». قد لا تعمل بعض المصادر بسبب التوقف أو تقييد المنطقة أو CORS أو عدم دعم الترميز. لا تزال تجربة Safari والتلفزيونات وأجهزة المستخدم غير مختبرة.

## مظهر الواجهة والخطوط
الوضعان الفاتح والداكن مستوحيان من مرجع Cloud Play. صور شعار الهيدر قصاصات مباشرة من صورة المستخدم. الخطوط Plus Jakarta Sans وPoppins وNoto Sans Arabic محفوظة محلياً، وتوجد نصوص رخص OFL في `public/fonts`.

## الحركة وإمكانية الوصول
حركات الدخول والبطاقات والقوائم والتبديل التلقائي للكاروسيل تعمل افتراضياً؛ يمكن إيقاف التبديل وحده أو تقليل الحركة من الإعدادات. يُحترم أيضاً إعداد تقليل الحركة في نظام التشغيل. الأفضليات تحفظ محلياً ولا ترسل للخادم.

## الشعار
شعار الهيدر الفاتح والمقدمة صورة كاملة مقتطعة من مرجع المستخدم وتعرض دون تمديد غير متناسب. المرجع محدود الدقة، لذا يُفضّل مستقبلاً استبداله بملف PNG شفاف أو SVG أصلي من صاحب الشعار.
