# المشغّل الخاص — Private owner-only player

مشغّل خاص لقنواتك وأفلامك ومسلسلاتك من سيرفر Xtream الخاص بك، مفتوح **لحساب المالك فقط**.
الموقع العام يبقى كما هو: مجاني، بمصادر مرخّصة، وبدون أي ربط بسيرفرك.

A private player for your own Xtream subscription, reachable **only by the owner account**.
The public site is unchanged: still free, still on licensed sources, with no link to your server.

---

## 1. لماذا خاص؟ / Why private?

حساب Xtream الشخصي اشتراك للاستخدام الشخصي. ربطه بموقع عام يعني إعادة بثّ لكل زوار
الإنترنت، وهذا يتجاوز حدود الاشتراك. لذلك:

- الصفحة `/my-tv` **غير مرتبطة** بالقائمة العامة، ومعلّمة `noindex`.
- كل مسارات `/api/xtream/*` تتحقق من هوية الحساب على السيرفر.
- الوصول محصور في قائمة بريدية صريحة `XTREAM_OWNER_EMAILS`.

التسجيل في الموقع مجاني ومفتوح للجميع، لذلك «مسجّل الدخول» **لا يكفي** — لازم يكون
الحساب ضمن قائمة المالكين. بدون هذه القائمة، لا أحد يدخل (fail-closed).

## 2. الإعداد / Setup

كل المتغيرات التالية **على السيرفر فقط**. لا تضع أي منها بادئة `NEXT_PUBLIC_`.

| Variable | Value | ملاحظة |
|---|---|---|
| `XTREAM_CATALOG_ENABLED` | `true` | يفعّل الربط |
| `XTREAM_BASE_URL` | `http://redchicks.xyz:2052` | عنوان سيرفرك، بدون `/player_api.php` |
| `XTREAM_ALLOW_HTTP` | `true` | مطلوب لأن سيرفرك HTTP |
| `XTREAM_USERNAME` | *(اسم المستخدم)* | سرّي |
| `XTREAM_PASSWORD` | *(كلمة المرور)* | سرّي |
| `XTREAM_OWNER_EMAILS` | `you@example.com` | بريد حسابك في الموقع — **مطلوب** |
| `XTREAM_PROXY_SECRET` | *(نص عشوائي طويل)* | مفتاح تشفير روابط التشغيل |

`NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY` موجودان مسبقاً (مفتاح عام آمن).

**خطوات التفعيل:**
1. أنشئ حساباً مجانياً في الموقع من صفحة `/login`.
2. ضع بريد هذا الحساب في `XTREAM_OWNER_EMAILS`.
3. ولّد `XTREAM_PROXY_SECRET` عشوائياً، مثلاً: `openssl rand -hex 32`.
4. أعد النشر (redeploy) حتى تقرأ الدوال المتغيرات الجديدة.
5. افتح `/my-tv` وأنت مسجّل الدخول.

## 3. كيف تبقى كلمة السر مخفية / How the password stays hidden

روابط Xtream تحتوي اسم المستخدم وكلمة المرور داخل المسار:

```
/live/<username>/<password>/123.m3u8      ← لا يصل المتصفح أبداً
```

بدلاً منها:

1. `/api/xtream/play` (يتطلب المالك) يُصدر **رمزاً مشفّراً** AES-256-GCM ينتهي بعد ٦ ساعات.
2. الرمز يحتوي مساراً **نسبياً** للسيرفر، فالوكيل لا يستطيع مخاطبة أي مضيف آخر.
3. `/api/xtream/stream` يفكّ الرمز، يجلب من سيرفرك، و:
   - يعيد كتابة قوائم M3U8 بحيث كل مقطع/مفتاح/جودة يصبح رمزاً جديداً عبر الوكيل.
   - يمرّر الفيديو مع دعم `Range` حتى يعمل التقديم والتأخير.
4. صور القنوات والأفلام التي على سيرفرك تمرّ عبر الوكيل أيضاً (لا mixed-content).

النتيجة: المتصفح لا يرى كلمة السر، ولا عنوان السيرفر، ولا أي رابط مباشر.

## 4. الحماية المطبّقة / Controls

- **Owner allow-list** على كل مسار، مع تحقق من JWT عبر Supabase Auth.
- **Fail-closed**: بدون `XTREAM_OWNER_EMAILS` لا أحد يدخل.
- **منع SSRF**: الرموز تحمل مساراً نسبياً فقط؛ يُرفض `//host` و `\` والعناوين المطلقة،
  والتحويلات (redirects) تُتبع داخل نفس المضيف فقط.
- **انتهاء صلاحية** الرموز + رفض أي عبث (GCM auth tag).
- **حدود**: ٨ ميغابايت للاستجابة، ١٢ ثانية للمهلة، ٢٤٠ طلب/دقيقة، ٣٠٠٠ عنصر للتصنيف.
- **تنظيف الأسماء** من اسم المستخدم/كلمة المرور لو أعادها السيرفر.
- **إيقاف فوري**: `XTREAM_CATALOG_ENABLED=false` يوقف الكتالوج والوكيل معاً.
- الموقع العام لم يتغيّر: `legacySourcesAllowed()` ما زال `false`.

## 5. الاختبارات / Tests

```bash
npm run test:private --workspace aether-web
```

٢٣ اختباراً تشغّل الوحدات الحقيقية ومسار الوكيل ضد سيرفر Xtream وهمي، وتثبت:
عدم تسرّب بيانات الدخول، رفض الرموز المزوّرة/المنتهية، منع مغادرة المضيف،
إعادة كتابة القوائم، عمل `Range`، وأن قائمة المالكين مغلقة افتراضياً.

---

## 6. حدود معروفة / Known limitations

- **HTTP**: سيرفرك يعمل على HTTP، فالاتصال بين السيرفر والمزوّد غير مشفّر.
  اطلب من مزوّدك عنوان HTTPS إن توفّر — عندها غيّر `XTREAM_BASE_URL` وأطفئ `XTREAM_ALLOW_HTTP`.
- **الصيغ**: المتصفح يشغّل MP4 و HLS. ملفات MKV/AVI قد لا تعمل.
- **مضيف واحد**: لو كان المزوّد يوزّع المقاطع على CDN بمضيف مختلف، تُحجب تلك المقاطع
  (حماية مقصودة). أخبرني إن ظهر هذا لنوسّع الوكيل بأمان.
- **الاتصالات**: اشتراكك يحدّد عدد الاتصالات المتزامنة؛ المشاهدة على عدة أجهزة قد تتعارض.
- **الحقوق**: أنت مسؤول عن أن يكون لديك حق استخدام هذا الاشتراك. هذا المشغّل للاستخدام
  الشخصي، وليس إعادة بثّ عامة.
