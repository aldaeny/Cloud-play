# شريط التنقل السفلي — تصميم الكبسولة المنزلقة

المرجع: صورة Pinterest أرسلها المستخدم (`https://pin.it/6nHRI5Wrn` + لقطتان).
شريط أسود عائم واحد: **العنصر النشط كبسولة أفقية بأيقونة + نص**، وبقية العناصر
أيقونات فقط، وزر بحث دائري منفصل عن الكبسولة (سطح المكتب/التابلت).

## ما تغيّر

| قبل | بعد |
| --- | --- |
| «نتش» (منحنى) يرتفع من حافة الشريط + دائرة بارزة للأيقونة النشطة | كبسولة أفقية داخل الشريط (بدون بروز خارجه) |
| كل العناصر بأيقونة + تسمية 10px | العنصر النشط فقط يعرض التسمية؛ الباقي أيقونات صافية |
| تموضع بقياس DOM + tween بمؤقّت (`setInterval`) | انتقال CSS خالص على `max-width`/`padding` — لا قياس DOM ولا مؤقّتات |
| لا يوجد زر بحث في الشريط | زر بحث دائري منفصل (≥700px)، وفي الهاتف يبقى الشريط بعرض كامل |
| شريط رمادي شبه شفاف | أسود شبه معتم `rgba(10,11,14,.92)` مع `blur` — وفي الفاتح: أبيض + كبسولة سوداء |

## كيف تعمل الحركة بدون قياس DOM

كل عنصر `.cp-nav-btn` يحمل `flex: 1 1 auto`. عند تفعيله:
`padding-inline` يزيد، و`max-width` للتسمية ينتقل 0 ← 150px، فيتمدد العنصر
ويضغط جيرانه بسلاسة (`transition .42s`). عند تغيير المسار تُغلق تسمية العنصر
القديم وتُفتح تسمية الجديد في نفس الإطار، فيبدو الشريط كأن الكبسولة «تسافر».
هذا صحيح في RTL وLTR وبين طيّات انتقال الصفحة (PageTransition) دون أي
استماع لـDOM أو مؤقّتات — وهي الطريقة التي كانت مطلوبة في المرحلة 5 لأن
الانتقالات الزمنية كانت «تتجمّد» أثناء طيّ الصفحة.

## التحقق (Chromium حقيقي، بناء الإنتاج)

- `npm run build` ناجح، `tsc --noEmit` ناجح، ESLint ناجح.
- `tests/live-layout.mjs`: **120 نجاح / 0 فشل** — 5 مقاسات × 4 أوضاع (عربي/إنجليزي،
  فاتح/داكن): لا تجاوز أفقي، الشريط ثابت أثناء التمرير، المساحة المحجوزة أسفل الصفحة
  ≥ ارتفاع الشريط (بما فيه زر البحث)، ولا عنصر تفاعلي مغطى عند أقصى تمرير،
  والتسمية الظاهرة في الكبسولة غير مقصوصة عموديًا.
- `tests/browser-smoke.mjs`: **16 نجاح / 0 فشل** — التنقل بين الراوترات الهجينة،
  ثبات المظهر/اللغة، ولا تمرير أفقي على 390/820/1920.
- قياس الانتقال: من «الرئيسية» (كبسولة 115px) إلى «الأفلام» (108px)، عرض الشريط
  ثابت 370px، صفر تجاوز.

## الملفات المعدّلة

- `apps/web/src/components/nav/GlobalNav.tsx` — إزالة النتش/القياس، إضافة زر البحث المنفصل.
- `apps/web/src/styles/global-nav.css` — إعادة كتابة الشريط بالكامل (كبسولة + حالات + استجابة).
- `apps/web/src/lib/nav-routes.ts` — توضيح أن الشريط ستة عناصر أساسية.
- `apps/web/tests/live-layout.mjs` — قياس «أعلى الشريط» يشمل زر البحث، وفحص الكبسولة بدل النتش.

## ملاحظات

- زر البحث يشير إلى `/search` (صفحة البحث الحقيقية في `pages/[section].tsx`).
- الشريط يُخفى تلقائيًا أثناء فتح المشغّل، ويظهر عند تصغيره (سلوك سابق محفوظ).
- تفضيل «تقليل الحركة» يعطّل الانتقال فورًا.
