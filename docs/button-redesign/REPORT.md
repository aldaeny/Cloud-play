## 1. الملخص التنفيذي

تم إنشاء **نظام موحّد للأزرار (Button Design System)** يعتمد حصرياً على التصميمين المرجعيين المرفقين، وتطبيقه على كل أزرار المشروع المشتركة بين الويب والهاتف، مع إزالة الأنماط القديمة للأزرار (الألوان، التدرجات، الظلال، التوهجات، الحدود، تأثيرات Hover/Active، والحركات القديمة) واستبدالها بتأثير **الحافة المتحركة (Animated Edge Light)**.

- **المرجع الأول (IMG_4495 — زجاج كحلي):** طُبّق على **الوضع الفاتح** `.site.theme-light`.
- **المرجع الثاني (IMG_4496 — زجاج رمادي/فضي):** طُبّق على **الوضع الداكن** `.site` / `.theme-dark`.

تطبيق الهاتف الفعلي (Expo) هو غلاف `WebView` يعرض واجهة الويب نفسها، لذا فإن نظام أزرار الويب يغطّي الهاتف والأجهزة اللوحية والويب تلقائياً.

## 2. التصميم الجديد (مستخلص من المرجعين)

| العنصر | الوضع الداكن (مرجع 2) | الوضع الفاتح (مرجع 1) |

| الشكل | مستطيل مدور 14px / حبّة 999px / دائرة 50% | نفسه |
| الحافة المتحركة | ضوء فضي يدور حول المحيط (`conic-gradient` + قناع) | ضوء أزرق-أبيض |
| Hover | إضاءة الحافة والظل فقط (بدون قفز/تكبير) | نفسه |
| Active | ظل ضغط داخلي (بدون تحجيم) | نفسه |
| Focus | حلقة `2px` ظاهرة (تُحترم إمكانية الوصول) | نفسه |

كل القيم معرّفة كـ **Tokens** في مكان واحد (`buttons.css`) ولا تتكرر تعريفات الأزرار في الصفحات.

## 4. ما تمت إزالته من الأزرار القديمة

- التدرجات البنفسجية/الوردية/السماوية (`#6c3bff`, `#7a3cff`, `linear-gradient(...)`).
- الظلال والتوهجات القديمة (`box-shadow` الملون، `cp-shimmer`, `cp-pulse`, `cp-play-pulse` على الأزرار).
- تأثيرات Hover/Active القديمة (القفز `translateY`, التكبير `scale`, الدوران `rotate`).
- الحركات القديمة الخاصة بالأزرار: `nav-highlight`, `cp-shimmer`, `cp-pulse`, `cp-liquid-glint` (حُذفت الـ keyframes لأنها أصبحت غير مستخدمة).
- تعريفات الأزرار المكررة والمبعثرة في `globals.css` (تم تجريدها إلى الخصائص الهندسية فقط، ثم توحيد المظهر في `buttons.css`).

## 5. إثبات عدم تغيير أي عنصر خارج الأزرار

تمت الإزالة برمجياً عبر محلّل **PostCSS** وليس يدوياً، وفق قاعدة صارمة:
- لكل قاعدة CSS تُستهدف الأزرار: تُحذف **الخصائص البصرية فقط** (خلفية، حدود، ظل، لون، حركة، شفافية…) وتُبقى **الخصائص الهندسية** (الأحجام، الحشو، الهوامش، العرض، الخط، التموضع…).
- القواعد المختلطة (زر + عنصر آخر) تُقسم: يبقى الجزء غير الزرّي **كما هو حرفياً**.

**نتيجة التحقق المستقل (`tools/verify-button-scope.mjs`):**
```
checked non-button selectors = 885   → جميعها متطابقة بايت-بايت مع الأصل
button/desc selectors        = 292   → حُذفت منها الخصائص البصرية فقط، ولم تُختَرع أي خاصية
removed keyframes            = nav-highlight, cp-shimmer, cp-pulse, cp-liquid-glint (أزرار فقط)
VERIFY PASS: no non-button declaration changed; nothing invented.
```
يمكن إعادة تشغيل الإثبات:
```bash
npm i -D postcss
node docs/button-redesign/tools/verify-button-scope.mjs
```
كما أن `git diff` يُظهر أن التغييرات في `globals.css` محصورة في خصائص الأزرار البصرية، وأن `apps/api` بلا أي تغيير.

## 8. الاستثناءات والقيود الموثّقة (وفق البند 8 من التعليمات)

لم يتم ابتكار أي تصميم بديل؛ سُجّلت الحالات التالية وأُصلحت ضمن النطاق المسموح:

1. **مفاتيح التبديل (Switches):** عناصر `<input type="checkbox">` (مثل «تقليل الحركة») هي عناصر نموذجية وليست أزرار `<button>`، لذا تُركت كما هي. مشغّل الفيديو يستخدم عناصر التحكم الأصلية للمتصفح ولم تُلمس («مشغّل الفيديو نفسه» محمي).
2. **البطاقات محمية:** `poster`, `browse-card`, `collection-card`, `open-movie-card`, `cp-reel-card` أبقيت بتصميمها الحالي بما فيه حافتها الحمراء المتحركة (البطاقات خارج النطاق). شريحة `poster-action` داخل البطاقة (تظهر في وضع معاينة التصميم فقط) تُعدّ محتوى بطاقة ولم تُعدّل.
3. **الأيقونات داخل الأزرار محمية:** رسوم SVG، وزخرفة مفتاح المظهر (الشمس/القمر/النجوم/السحب/المقبض)، وشارة `firebase-play` — كلها أبقيت. الذي تغيّر هو **سطح الزر** فقط (الخلفية/الحافة)، بما في ذلك إزالة تدرّج السماء القديم من خلفية مفتاح المظهر واستبداله بالزجاج.
4. **نقاط الترقيم (Dots):** أُبقيت أبعادها كما هي وأُعيد تلوينها بلون الحافة المرجعي؛ لا تُطبّق حلقة الحافة المتحركة على مؤشر بحجم 7px.
5. **الزر الشفاف `cp-reel-select`:** طبقة نقر غير مرئية فوق البطاقة، أُبقيت شفافة (تطبيق الزجاج عليها كان سيحجب البطاقة).
6. **تطبيق Expo الأصلي:** زر «إعادة المحاولة» الوحيد خارج WebView طُبّق عليه لون/حدود/شكل الزجاج المرجعي. React Native لا يدعم `backdrop-filter` ولا أنيميشن الحافة دون إضافة اعتماديات جديدة (تغيير هيكلي ممنوع)، لذا سُجّل هذا القيد منصياً.
7. **عميلا iOS (SwiftUI) وAndroid (Compose) الأصليان:** واجهات أصلية منفصلة لا يمكن تطبيق زجاج CSS/أنيميشن الحافة عليها، ولا يمكن ترجمتها/اختبارها في هذه البيئة (لا Xcode/Android SDK). تطبيق الهاتف الذي يشغّل تجربة Cloud Play هو غلاف Expo (WebView) ويرث نظام أزرار الويب بالكامل. سُجّل هذا كقيد منصة.
8. **حافة 1px:** هي جزء أصيل من التصميم المرجعي. وبفضل `box-sizing: border-box` تبقى الأزرار ذات الأحجام الثابتة مطابقة لأبعادها السابقة.
