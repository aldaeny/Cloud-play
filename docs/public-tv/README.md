# البث المباشر العام — Public free live TV

قنوات مجانية للعامة على `/live` — **بدون تسجيل دخول، بدون اشتراك، بدون إعداد**.
بالإضافة إلى زر **«مشغّلي الخاص»** الذي يظهر تلقائياً لحساب المالك فقط.

Free public live TV on `/live` — no sign-in, no subscription, no configuration.
Plus a one-tap **My private player** button that appears only for the owner account.

### قواعد الإدراج / Inclusion rules

كل قناة يجب أن تحقق **كل** الشروط:

1. البث من نطاق المالك نفسه أو الـ CDN الخاص به — لا وسيط ولا إعادة بث.
2. منشور علناً لمشغّل الويب المجاني الخاص بالمالك — بدون بيانات دخول، بدون رموز، بدون DRM.
3. HTTPS بالكامل — لا mixed-content على صفحة HTTPS.
4. تم جلب قائمة التشغيل الرئيسية والتحقق منها فعلياً.

لهذا السبب القائمة **صغيرة ومفحوصة يدوياً**، وليست تجميعاً من قوائم IPTV عامة:
التجميع لا يستطيع إثبات من ينشر كل بث. كل قناة تحتفظ برابط صفحتها الرسمية.

## 2. زر المالك / The owner button

`OwnerPlayerLink` يظهر فقط لحساب المالك:

- **الزوار المجهولون لا يسبّبون أي طلب** — المكوّن يتوقف قبل الجلب إذا لا يوجد حساب.
- النتيجة محفوظة لكل مستخدم، فالتنقل بين الصفحات لا يعيد السؤال.
- يختفي على صفحة `/my-tv` نفسها.
- أي فشل → يبقى مخفياً. لا يعطّل الصفحة أبداً.

يظهر في الرئيسية وفي كل صفحات الأقسام.

---

## 3. ما لم يتغيّر / What did not change

- `/my-tv` ما زال خاصاً، `noindex`، ومحصوراً بقائمة المالكين.
- كل مسارات `/api/xtream/*` ما زالت تطلب المالك.
- `legacySourcesAllowed()` ما زال `false`.
- لا كلمة سر ولا عنوان السيرفر الخاص في أي صفحة عامة.
- قائمة المشغّل المرخّصة (`/api/iptv/licensed`) تُضاف تلقائياً أسفل القنوات العامة إن كانت مُعدّة.

---

## 4. الأداء / Performance

قائمة القنوات **تُصيَّر على السيرفر** (`getStaticProps`)، فالقنوات تظهر في HTML الأول
بدون انتظار طلب شبكة، وتكون قابلة للأرشفة. نقطة `/api/iptv/public` قابلة للتخزين على CDN
(`s-maxage=3600`). لا صور خارجية — البطاقات نصية سريعة.

## 5. الاختبارات / Tests

```bash
npm run test:public  --workspace aether-web   # 10 checks
npm run test:films   --workspace aether-web   # 15 checks (public film library)
npm run test:private --workspace aether-web   # 23 checks (regression)
```

تثبت: كل الروابط HTTPS بدون بيانات دخول، لا تسرّب لأي سر، النقطة عامة بدون مصادقة،
القنوات العراقية موجودة، الحارس يرفض الروابط غير الآمنة، والمشغّل الخاص ما زال مقفلاً.

## 6. حدود معروفة / Known limitations

- **التشغيل يعتمد على المصدر**: الاتصال مباشر من المتصفح بالمزوّد. إذا توقّف المصدر
  أو منع التشغيل من مواقع أخرى (CORS)، تظهر رسالة إعادة محاولة + رابط الصفحة الرسمية.
  هذا مقصود: لا يمرّ الفيديو عبر سيرفرنا، فلا استهلاك bandwidth على الاستضافة.
- **التوفر يتغيّر**: روابط البث المجاني قد تتغير. أعِد الفحص دورياً.
- **الحقوق**: هذه بثوث ينشرها أصحابها مجاناً للعموم. للاستخدام التجاري أو إعادة البث
  واسعة النطاق، راجع شروط كل جهة مالكة.
