## ١. الملخص التنفيذي

أُعيد بناء صفحة التلفزيون المباشر (`/live`) لتدعم **طريقتَي عرض** (شبكة / قائمة مصغرة)،
**مشغلاً منبثقاً** يفتح فوق الصفحة بدل الانتقال إلى صفحة أخرى، **خمسة أنماط ترتيب**،
و**عرضاً افتراضياً (Virtualization)** يتعامل مع ٧٥٠٠ قناة وأكثر بسلاسة على الجوال.

الهوية البصرية للمنصة لم تتغير: الشعار، الألوان، الخطوط، شريط التنقل السفلي وزره المركزي
البارز، الانتقالات، الحسابات، وبقية الصفحات كما هي. أُضيف Tailwind **بنطاق معزول تماماً**
حتى لا يمس أي صفحة قديمة.

## ٣. طريقة العرض والحفظ

- المفتاحان: `cloudplay-channel-view` (`grid` \| `list`) و`cloudplay-channel-sort`.
- القيمة الافتراضية على الخادم والمتصفح: **شبكة + الترتيب الافتراضي**، فلا يحدث وميض ولا اختلاف hydration.
- الاختيار يبقى بعد إعادة التحميل والتنقل بين الصفحات.

## ٤. أنماط الترتيب الخمسة

| المفتاح | العربية | السلوك |
| --- | --- | --- |
| `default` | الافتراضي | ترتيب قائمة المصدر كما هو، دون أي تعديل. |
| `az` | أبجدي (أ-ي) | `Intl.Collator` بلغة الواجهة (عربي أو إنجليزي)، حساسية أساسية وترقيم طبيعي. |
| `country-group` | حسب الدولة | تجميع حسب اسم الدولة المترجم؛ غير المحددة في النهاية. |
| `quality-desc` | حسب الجودة | 4K ← 1080p ← 720p ← SD ← غير معلنة. |
| `favorites-first` | المفضلة أولاً | تثبيت المفضلة أعلى القائمة مع بقاء ترتيب الباقي ثابتاً. |

> **الجودة هي المعلنة من المصدر فقط.** لا نخمّن دقة البث، والقناة بلا جودة معلنة تظهر بلا وسم وتُرتَّب في النهاية.

## ٥. المشغل المنبثق

- **الفتح:** النقر على أي مكان في الصف، أو زر «تشغيل»، أو بطاقة الشبكة.
- **البث:** يعيد استخدام `VideoPlayer` الموجود (‏`hls.js` لـ `.m3u8`، `dash.js` لـ `.mpd`، MP4 أصلي) بدل بناء مشغل ثانٍ — نفس الجودة والصوت والترجمة وإعادة المحاولة وحالات الفشل.
- **التشغيل التلقائي:** يبدأ فور الفتح، وإذا منعه المتصفح يظهر زر تشغيل صريح (لا تظاهر بنجاح وهمي).
- **الإغلاق:** زر X، مفتاح Escape، أو النقر على الخلفية. عند الإغلاق **يُفصل المكوّن كلياً**، فيُدمَّر محرك البث ويُنزَع مصدر الفيديو ويتوقف استهلاك البيانات فوراً.
- **التصغير:** نافذة عائمة أسفل يمين الشاشة تستمر بالبث أثناء التصفح، مع زر استعادة. إذا دعم المتصفح Picture-in-Picture الأصلي تُستخدم نافذة النظام وتنكمش البطاقة إلى شريط عودة. **شريط التنقل السفلي يبقى ظاهراً** في الوضع المصغّر.
- **إمكانية الوصول:** `role="dialog"` و`aria-modal`، حبس التركيز داخل النافذة، وإعادة التركيز إلى الصف الذي فتحها عند الإغلاق، وقفل تمرير الصفحة خلفها.

## ٦. الأداء مع ٧٥٠٠ قناة

قياسات فعلية من Chromium حقيقي (٣٩٠×٨٤٤، قائمة مصغرة، كتالوج اختباري من ٧٥٠٠ صف):

| المقياس | النتيجة |
| --- | --- |
| الصفوف المركّبة في DOM | **١٦ صفاً** (٣٦ عقدة) بدل ٧٥٠٠ |
| أقصى صفوف أثناء ٢٥ قفزة عبر الكتالوج كامل | **٢٣ صفاً** |
| سرعة التمرير السريع | **١٧٫٣ مللي ثانية/إطار** مقابل خط أساس ١٥٫٧ (أي ~٥٨ إطاراً/ثانية) |
| أطول مهمة حاجبة (long task) | **٠ مللي ثانية** |
| الوصول إلى القناة رقم ٧٥٠٠ | ناجح |

التقنيات: صفوف بعرض ثابت ٥٦ بكسل، `getItemKey` ثابت لكل قناة، `React.memo` للصف،
`useCallback` لدوال التشغيل والإغلاق، و`useMemo` لمجموعة المفضلة.

## ٧. عزل Tailwind (لا تأثير على بقية الموقع)

- `prefix: 'tw-'` — كل أداة جديدة تبدأ بـ `tw-`.
- `important: '.cp-tw'` — الأدوات تعمل فقط داخل الحاويات الجديدة (القائمة، شريط الأدوات، والمشغل عبر portal).
- `corePlugins.preflight: false` — **لا إعادة ضبط عامة**؛ طبقة `base` تُخرج فقط متغيرات `--tw-*` التي تحتاجها أدوات الظل والتدرّج والضبابية.
- `content` محصور بالمكونات الجديدة.
- تطبيع مصغّر داخل `.cp-tw` فقط لإلغاء تنسيق الأزرار العام القديم.
- اختبار متصفح يؤكد أن `/` و`/movies` و`/series` و`/settings` **لا تحتوي أي صنف `tw-`** وأن هوامشها وخطوطها لم تتغير.

الألوان المستخدمة داخل النطاق الجديد: `#0f0f10`، `#1f1f22`، `#2a2a2e`، `#33333a`، `#a1a1aa`، مع `#ec4899` و`#8b5cf6` — وهي درجات متناغمة مع هوية المنصة الحالية.

## ٨. دعم RTL الكامل

- الحاويات الجديدة تحمل `dir` حسب لغة الواجهة، وتستخدم خصائص منطقية (`inset-inline-start`, `ms-auto`).
- في RTL: النجمة يميناً ثم الشعار فالاسم فزر التشغيل يساراً. في LTR ينعكس الترتيب.
- القائمة الافتراضية تعمل بالاتجاهين دون تمرير أفقي (تم التحقق على ٣٩٠ و١٤٤٠ بكسل).

## English summary

`/live` now offers a persisted **Grid / Compact list** switch, a **pop-up HLS player**
(reusing the existing `hls.js`/`dash.js` engine) with autoplay, custom controls, LIVE badge,
favorite, minimize-to-floating-window, and Escape/backdrop/X dismissal that fully unmounts
the stream. Five sort modes (default, A–Z/أ–ي, country, quality, favorites-first) run through a
pure, stable, locale-aware engine. The list is virtualized with `@tanstack/react-virtual`:
**16 rows mounted for 7,500 channels**, 17.3 ms/frame against a 15.7 ms baseline, zero long tasks.
Tailwind is fully scoped (`tw-` prefix, `.cp-tw` importance scope, no preflight) so no existing
page changes. RTL and LTR both verified. **299 checks pass**; tsc/lint clean; build succeeds.
