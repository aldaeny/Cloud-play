# Authentication and authorization endpoint matrix

Generated from controller decorators by `node apps/api/scripts/auth-matrix.cjs`. **Inventory, not a security certification.** 88 declared routes.

D1 cutover is IN PROGRESS: only the additive hybrid profiles endpoint uses SupabaseAuthGuard. Legacy user/staff credentials and JWT endpoints remain for compatibility. Rights and Entitlement are service modules without controllers. All 13 modules load in composition tests, not all are integrated into the frontend.

*Global rate limiting is installed by production main.ts (100/min/IP, 10/min/IP auth). Test application bootstrap does not automatically install main.ts middleware. Verify deployed proxy topology before trusting forwarded headers. The Next.js profile bridge also uses the catalog bucket.

Real JWT expiry/signature, token-class separation, malformed subject, disabled user, forged claims, staff-role tenant mismatch and missing permission checks: legacy-auth.security.spec.ts (database fixtures). Supabase invalid-token/unavailable/inactive/unprovisioned and forged ownership coverage: supabase-auth.*.spec.ts and hybrid-profiles.http.spec.ts. A valid bearer token can be replayed until expiry/revocation constraints; single-use access tokens are not implemented. StaffUser has no disable/status field, so disabled-staff enforcement is NOT implemented. Do not infer session revocation immediacy from calling Supabase getUser alone.
