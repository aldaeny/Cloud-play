# Cloud Play mobile shell — مرحلة أولية، ليست تطبيقاً منشوراً

أضيف هيكل Expo SDK 54 يحافظ على الشيفرة الأصلية الموجودة في `mobile/android` و`mobile/ios`. هو غلاف WebView للموقع الحقيقي، وليس تطبيق بث أصلياً أو بديلاً لإكمال حسابات API. لا يتضمن رابطاً وهمياً: عند عدم ضبط الموقع تظهر رسالة إعداد. التنقل داخل WebView محصور بأصل HTTPS المحدد، والروابط الخارجية HTTPS المختارة تُطلب في متصفح النظام بحسب دعم المنصة؛ لا يمكن افتراض تغطية جميع التنقلات وأجهزة WebView دون اختبار أجهزة حقيقية.

```sh
cd mobile/expo
npm ci
npm run check
# بعد وجود موقع حقيقي يعمل ومتاح للعامة فقط:
EXPO_PUBLIC_CLOUDPLAY_URL="https://YOUR-VERIFIED-PUBLIC-DOMAIN" npm start
# تجميع JavaScript للمنصتين، ليس APK/IPA:
npm run export:android
npm run export:ios
```

`.npmrc` يحدد `legacy-peer-deps=true` لضمان التوافق مع lock المستخدم. اختُبرت TypeScript وتجميع حزم Android وiOS و`expo install --check` فقط. لم يجر تثبيت على جهاز، أو محاكاة Android/iOS، أو اختبار HLS/ترجمات/اشتراكات داخل WebView، أو إنشاء APK/IPA، أو نشر متاجر أو تخصيص معرفات التطبيقات/التوقيع. يستلزم ذلك بيئات Android وmacOS/Xcode وحسابات توزيع وفق سياسات كل متجر. غلاف الويب وحده قد لا يفي بسياسات المتجر. لا تُدخل أسراراً في متغيرات `EXPO_PUBLIC_*` لأنها تدخل الحزمة.

تدقيق الاعتماديات بعد الإصلاح غير القسري: 26 تنبيهاً (1 مرتفع، 24 متوسطاً، 1 منخفضاً)؛ المرتفع المتبقي `image-size` ضمن Metro لمعالجة صور البناء، ولا يعني تلقائياً قابلية استغلال التطبيق عند المشاهد. استُبدل PostCSS بنسخة مصححة باعتماد override واختُبر التجميع، ولم تُفرض ترقية `image-size` رئيسية قد تكسر Metro. راجعها وأصلح سلسلة البناء قبل إصدار تطبيق.
